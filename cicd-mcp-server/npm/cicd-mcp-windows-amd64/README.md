# @google-cloud/cicd-mcp-windows-amd64

This package contains the Windows amd64 binary for the CI/CD MCP Server.

## Installation

This package is typically installed automatically as an optional dependency of the main `@google-cloud/cicd-mcp` package.

```bash
npm install @google-cloud/cicd-mcp-windows-amd64
```
